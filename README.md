# 개인정보처리방침

**메이플스토리 인벤 - 넌 차단이다**(이하 "확장 프로그램")는
확장 프로그램 기능 제공을 위해 최소한의 정보만 처리합니다.

## 1. 처리하는 정보

확장 프로그램은 다음 정보를 처리할 수 있습니다.

- 무작위로 생성된 익명 설치 식별자
- 사용자가 차단한 인벤 닉네임
- 차단 목록 동기화 시각 및 횟수
- 확장 프로그램 설정값

## 2. 이용 목적

처리되는 정보는 다음 목적으로만 사용됩니다.

- 사용자 차단 목록 관리 및 동기화
- 차단 랭킹 집계
- 확장 프로그램 설정 유지
- 확장 프로그램 기능 제공 및 안정적인 운영

## 3. 수집하지 않는 정보

확장 프로그램은 다음 정보를 수집하지 않습니다.

- 인벤 계정 아이디 및 비밀번호
- 이메일 주소
- 실명 및 연락처
- 결제 및 금융 정보
- 게시글 및 댓글의 본문 내용
- 위치 정보

## 4. 정보의 저장

일부 정보는 차단 목록 동기화 및 랭킹 기능 제공을 위해
서버에 저장될 수 있습니다.

확장 프로그램의 설정값 및 로컬 차단 정보는
사용자의 브라우저 저장소에 저장됩니다.

## 5. 제3자 제공 및 판매

수집된 정보를 판매하지 않으며,
확장 프로그램의 기능 제공 목적 외의 용도로
제3자에게 제공하지 않습니다.
